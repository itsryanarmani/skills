# The 20 popular thumbnail formats

These are described in our own words from a public design thread
(https://x.com/designbykashyap/status/2125271065823936795, "20 more thumbnail
formats you can steal today", 20 images, one format each). We link the post and
copy none of its artwork. Each row says what the format is, when it works, and
the nearest layout in the gallery template (`assets/gallery`).

## How to pick one

1. Match the format to what the viewer wants: proof (5, 15), fear (11, 12),
   curiosity (14, 16), trust (9), comparison (2), outcome (7, 19).
2. Keep the format, change the content. A format is a layout idea. The words,
   colours and photos must be yours.
3. A format that needs a number you do not have (3, 7, 8, 19) is wrong. Do not
   invent a number to fit it.
4. Several formats fit personal or outreach videos with no money angle: 9, 13,
   14, 17, and the question styles. Money formats do not.
